# Slot server

Серверный API для демо Crowns of Kemet. Итог раунда, баланс, выигрышные линии и бонусы вычисляются только на сервере. Реальные правила оригинальной игры неизвестны; таблица ниже задаёт правила именно этого демо.

## Запуск

Из корня репозитория:

1. `pnpm install`
2. `docker compose -f apps/server/compose.yaml up -d`
3. Скопировать `apps/server/.env.example` в `apps/server/.env`.
4. `pnpm server:dev`

Сервер слушает `127.0.0.1:3001`. Для локальной разработки разрешён Origin `http://localhost:5173`. Адрес базы и список разрешённых Origin задаются в `.env` сервера. Контейнер создаёт базу, сервер создаёт таблицы при первом старте. Демонстрационные учётные данные PostgreSQL из `compose.yaml` нельзя использовать при публичном развёртывании.

## Протокол

- `POST /api/slot/session` создаёт сессию и возвращает её состояние; начальный баланс — 250000 игровых монет.
- `GET /api/slot/state` возвращает баланс, последнюю ставку, состояние Free Spins, допустимые ставки и таблицу линий. Заголовок: `Authorization: Bearer <sessionId>`.
- `GET /api/slot/rounds/<requestId>` восстанавливает сохранённый результат раунда с тем же заголовком.
- `GET /api/slot/ws` открывает WebSocket. Команды и ответы описаны в `packages/contracts/src/index.ts`.

Команда обычного вращения: `{"type":"SPIN","sessionId":"<UUID>","requestId":"spin_req_001","bet":15,"level":1,"coinValue":0.02}`. Во время бонуса отправляется `{"type":"FREE_SPIN","sessionId":"<UUID>","requestId":"free_req_001"}`. Каждый ответ имеет тип `ROUND_RESULT` и содержит полный `result`, либо тип `ERROR` с кодом. Поля `isWin` и `netCoins` явно показывают выигрыш и чистое изменение баланса. Повтор команды с тем же `requestId` в одной сессии возвращает сохранённый результат; параллельные команды этой сессии сериализуются блокировкой строки БД. Запрос `SPIN` во время Free Spins отклоняется.

## Правила демо

На поле 5 барабанов по 3 символа. В `reels` внешний массив перечисляет барабаны слева направо, внутренний — символы сверху вниз. `positions` содержит `[reelIndex, rowIndex]`, индексы с нуля. Пять линий указаны в ответе `/state`; `lineId` начинается с 1.

`BET` разрешён от 1 до 20, `LEVEL` от 1 до 10. Ставка в монетах равна `BET × LEVEL`; `COIN VALUE` задаёт денежный номинал монеты и не изменяет число монет, списываемых с игрового баланса. Разрешённые номиналы: 0.01, 0.02, 0.05, 0.10, 0.20, 0.50 и 1.00. Для суммы в деньгах клиент умножает число монет на номинал. Выигрыш линии — коэффициент символа для 3/4/5 совпадений × общая ставка в монетах × множитель Wild. Коэффициенты находятся в `src/game/rules.ts`.

`wild` подменяет любой обычный символ и расширяется на весь барабан с множителем 3 для затронутой линии. В Free Spins такой барабан остаётся липким до конца бонуса. Три или более `highScarab` в базовом вращении дают 8 Free Spins; в бонусе повторный запуск отключён. Бонусные вращения не списывают ставку. Сервер генерирует случайные остановки через `crypto.randomInt` и сохраняет итоговый JSON и состояние сессии одной транзакцией PostgreSQL. `animations` — подсказки о последовательности показа, финансовый результат они не меняют.

`sessionId` в этом демо служит секретом доступа к балансу. До использования с реальными деньгами потребуются учётные записи, полноценная авторизация, отдельные проверки игровых правил и сертификация под нужную юрисдикцию.
